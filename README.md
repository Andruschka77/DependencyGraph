# Dependency Graph Visualizer

Инструмент для анализа и визуализации графа зависимостей пакетов NPM и других репозиториев.

## Возможности

- 📦 **Анализ зависимостей** пакетов из NPM registry и локальных файлов
- 🔄 **Построение графа зависимостей** методом DFS с ограничением глубины
- 🔍 **Обнаружение циклических зависимостей** с детализацией циклов
- 🎨 **Визуализация через D2** (текстовый формат + PNG изображения)
- 🌲 **Вывод зависимостей в виде ASCII-дерева** с подсветкой циклов
- 🧪 **Режим тестирования** с локальными JSON файлами
- 🔧 **Фильтрация пакетов** по названию
- 📊 **Топологическая сортировка** для определения порядка загрузки
- 🔄 **Кэширование запросов** к NPM registry

## Требования

- **Python 3.7+**
- **D2** (опционально, для генерации PNG изображений)

## Установка D2 (для генерации изображений)

### Windows:
```
winget install d2
```

## Примеры использования:
1. Анализ реального пакета из NPM registry:
```
python main.py --package react --url https://registry.npmjs.org --max-depth 3 --visualize --ascii-tree
```
2. Тестовый режим (локальный файл):
```
python main.py --package React --file test_complex.json --visualize --ascii-tree --generate-image
```
3. Анализ с фильтрацией пакетов:
```
python main.py --package vue --url https://registry.npmjs.org --filter test --max-depth 2 --visualize
```

## Параметры командной строки:

| Параметр | Короткая версия | Описание | Обязательный | По умолчанию |
|----------|-----------------|-----------|--------------|-------------|
| `--package` | - | Имя анализируемого пакета | ✅ Да | - |
| `--url` | - | URL репозитория NPM | Для реального режима | - |
| `--file` | - | Путь к файлу тестового репозитория | Для тестового режима | - |
| `--test-mode` | - | Включить тестовый режим работы | ❌ Нет | `False` |
| `--max-depth` | - | Максимальная глубина поиска зависимостей | ❌ Нет | `5` |
| `--filter` | - | Исключить пакеты, содержащие подстроку | ❌ Нет | `""` |
| `--visualize` | - | Визуализировать граф зависимостей | ❌ Нет | `False` |
| `--ascii-tree` | - | Показать ASCII-дерево зависимостей | ❌ Нет | `False` |
| `--generate-image` | - | Сгенерировать изображение графа | ❌ Нет | `False` |
| `--help` | - | Показать справку | ❌ Нет | - |

```
│ ├── display_load_order() # Топологическая сортировка
│ └── visualize_dependencies() # Управление визуализацией
│
├── DependencyGraph.py # Модель графа зависимостей
│ ├── add_package() # Добавление пакета в граф
│ ├── add_dependency() # Добавление зависимости

│ ├── get_cycles() # Поиск всех циклов
│ ├── get_load_order() # Топологическая сортировка
│ └── get_dependency_levels() # Уровни зависимостей (BFS)
│
├── DependencyVisualizer.py # Визуализация графа
│ ├── generate_d2_diagram() # Генерация D2 кода
│ ├── display_ascii_tree() # Построение ASCII-дерева
│ ├── generate_and_display_image() # Генерация PNG изображения
│ └── compare_with_npm_tools() # Сравнение с npm инструментами
│
├── NPMRepository.py # Работа с NPM registry
│ ├── get_package() # Получение информации о пакете
│ ├── get_dependencies() # Получение списка зависимостей
│ └── _get_npm_dependencies() # Внутренний метод запроса к API
│
├── FileRepository.py # Работа с локальными файлами
│ ├── _load_packages() # Загрузка данных из JSON
│ ├── get_package() # Получение информации о пакете
│ └── get_dependencies() # Получение списка зависимостей
│
├── test_simple.json # Тестовые данные: простая структура
├── test_cyclic.json # Тестовые данные: циклические зависимости
├── test_complex.json # Тестовые данные: сложный граф
│

```
